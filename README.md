### Hi, I'm Piia

Senior UX Design Leader with 20 years in industrial design systems.  
Double M.Sc. — Cyber Security (University of Jyväskylä) + Information Systems (University of Oulu).

I bridge design leadership and security engineering — building tools that make secure, accessible software the default.

Off the clock I'm teaching a desktop robot named Jonathan to say when the bus leaves, and teaching Minecraft doors to check keycards before they open. Turns out both are access-control problems. 🤖🪪

#### Minecraft

> SITE-19 is an SCP prison roleplay server on Paper 26.3, played with **vanilla clients**: no mods, everything done with server resource packs, packets, dialogs and shaders. About 25 plugins, all built for it. The same access-control and safety instincts as the day job, at play. 🧱🔐

| | |
|---|---|
| [Firearms](https://github.com/alavesa/firearms-plugin) | Ray-based guns with a first-person display-entity rig, live viewmodel editor, eased recoil, ejected casings, grenades and a flashbang. Verified on a real client. 🔫 |
| [CCTV](https://github.com/alavesa/cctv-plugin) | Cameras, a full-screen camera view and live monitors with animated figures on the feeds. One jar and one pack serve both 26.2 and 26.3. 📹 |
